# Mandi Server

---
An MCP (Model Context Protocol) server that gives LLM clients (Claude Desktop, LangGraph agents, MCP Inspector) access to Indian mandi (agricultural market) price data from the CEDA Agri Market API by Ashoka University.

The data is the cleaned Agmarknet dataset (daily commodity prices and arrivals from government-regulated mandis, 2000 to present). It is historical data and lags by a few months, so it is suited to trend and seasonality analysis, not "today's price".
